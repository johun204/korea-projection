# USB Wi-Fi 동글 켜기·끄기·지우기 (포크 1.7.3.1)

내비에 Wi-Fi 부품이 없는 차(K8 GL3 등)에서 ipTIME A3000MINI(Realtek RTL8812BU, `0bda:b812`)로 무선 안드로이드 오토를 쓰는 기능입니다.
시스템 파일(`/system`)은 바꾸지 않습니다. 끄거나 지우면 동글을 쓰기 전 상태로 돌아갑니다.

## 동작 조건

동글 기능은 아래가 모두 맞을 때만 드라이버를 올립니다.

- 끔 표시가 없음(`kp-dongle-off`로 끄지 않음)
- **동글 보호 모드**(HMG-API 모드 `kp-dongle-aa-guard`)가 설치되어 있고 켜져 있음
  순정 안드로이드 오토는 USB 장치를 꽂으면 폰으로 보고 연결 요청을 보내는데, 이 동글은 그 요청에 칩이 멈춥니다. 보호 모드가 이 동글에만 그 요청을 막습니다.
- 내비 커널이 드라이버를 만든 커널과 같음(내비 소프트웨어를 업데이트하면 올리지 않음)
- 동글을 쓰다 내비가 2번 재시작된 기록이 없음(있으면 스스로 멈춤, `켜기`로 풀림)

## 조작 USB

FAT32 USB 맨 위에 `dongle-ctl-usb/`의 `NEMESIS.data`, `NEMESIS.sh`를 복사하고, **아래 빈 파일 중 하나만** 만듭니다.

| 파일 | 하는 일 |
|---|---|
| `kp-dongle-on` | 켜기. 보호 모드가 없으면 넣습니다(넣은 뒤 **재부팅**). 막힘 기록도 풉니다. |
| `kp-dongle-off` | 끄기. 동글 핫스팟을 멈추고 드라이버를 내리고 보호 모드를 끕니다. |
| `kp-dongle-remove` | 지우기. 동글 때문에 생긴 것을 모두 되돌립니다(아래). 재부팅하면 동글을 쓰기 전 상태입니다. |
| `kp-dongle-status` | 상태만 봅니다. |

내비가 다 켜진 뒤 꽂고 **예**를 누릅니다. 완료 창이면 성공, 실패 창이면 USB의 `KP-dongle-ctl/<동작>-N.txt`를 보세요.

**지우기가 되돌리는 것:** 드라이버와 동글 핫스팟, 보호 모드, 동글로 Wi-Fi 칩이 생겨 Korea Projection이 넣은 HMG-API 무선 모드(다른 변경이 섞여 있으면 적용하지 않고 알림), 동글 때문에 만든 HMG-API 칩 기록, Wi-Fi 잠금, 순정 핫스팟 저장값, 동글 기록. Korea Projection과 HMG-API 자체는 그대로 둡니다.

## HMG-API 앱에서

HMG-API 앱의 모드 목록에서 **USB Wi-Fi dongle guard (Korea Projection)** 를

- **끄면**: 보호가 바로 멈추고, Korea Projection이 30초 안에 동글 핫스팟을 멈추고 드라이버를 내립니다.
- **켜면**: 재부팅 뒤부터 동작합니다. 꺼져 있는 동안 꽂아 둔 동글은 칩이 멈춰 있을 수 있으니 한 번 뺐다 꽂으세요.
- **지우면**: 끄기와 같습니다. 다시 쓰려면 조작 USB의 `kp-dongle-on`.

## 완전히 순정으로

Korea Projection을 지우면(NEMESIS Manager → Korea Projection → Uninstall) 동글 드라이버를 내리고 보호 모드와 무선 모드, 칩 기록도 함께 지웁니다.
